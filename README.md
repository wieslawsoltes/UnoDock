# UnoDock

Independent AvalonDock-compatible docking for Uno Platform / WinUI.

Implementation and validation are in progress. Compatibility is measured against a pinned, declaration-only public API inventory; no upstream implementation, XAML templates, resources, or artwork are included.

The target is source-level migration with explicit WPF-to-Uno type mappings, not binary compatibility with WPF. A passing API inventory alone does not establish behavioral compatibility.
